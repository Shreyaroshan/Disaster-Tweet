# Results upload plan

Each member uploads the results included in their model handoff: per-model final metrics, predictions, errors, selection evidence, search/replication histories and training log. Preserve the packaged repository paths. Do not include checkpoints, vector arrays or raw datasets.

These runs were generated centrally with AI assistance. Review and reproduce where needed, recording actual contributions. New runs should use a distinct run name.

Combined comparison files, paired analysis, evaluation lock, shared verification and report figures remain local in the integration package until all four contributions are integrated. Previous published outputs remain in Git history; this change does not rewrite history.
